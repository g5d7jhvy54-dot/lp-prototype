# 原型公网访问 · 部署说明

> **走 GitHub Pages（推荐）→ 直接跳到 B0，网页操作 4 步，3 分钟，不用命令行。**

> 三个原型均已**完全自包含**（图片、样式、脚本全部内联，0 外链、0 网络请求）。
> 所以部署只需要上传 **6 个文件**，不需要任何目录结构、不需要构建。

```
deploy/
├── index.html     入口页（三线入口 + 使用说明）
├── rz.html        副业 · 蕊智创作课堂
├── qt.html        投教 · 钱堂通识课堂
├── zq.html        配音 · 知奇声音课堂
├── README.md      仓库首页说明（可选）
├── .nojekyll      空文件，关闭 Jekyll（建议保留）
└── 部署说明.md     本文件（不必上传）
```

三种方式，按使用场景选：

| 方式 | 适合 | 耗时 | 成本 | 缺点 |
|---|---|---|---|---|
| **A 临时隧道** | 今天就要发个链接给人看 | 3 分钟 | 免费 | 本机关机即失效 |
| **B GitHub Pages**（推荐） | 长期链接、发给客户/同事 | 10 分钟 | 免费 | 国内访问偶发慢 |
| **C 腾讯云 CloudBase** | 微信内打开要稳、要长期 | 20 分钟 | 有免费额度 | 需实名 |

---

## A · 临时隧道（最快，不需要任何账号）

需要本机装着 `cloudflared`：

```bash
# 安装（一次）
brew install cloudflared

# 起本地服务
cd deploy
python3 -m http.server 8080

# 另开一个终端，把本地端口暴露到公网
cloudflared tunnel --url http://localhost:8080
```

终端会打印一个 `https://xxx-xxx-xxx.trycloudflare.com` 的地址，直接发给别人即可。

- 地址是随机的，**每次重启都会变**。
- **你电脑关机/断网就失效**，所以只适合临时评审。
- 不需要注册、不需要账号、不经过任何第三方后台。

> 若不想装 cloudflared，也可以用 `npx localtunnel --port 8080`，但访问时会多一个确认页，体验不如前者。

## B · GitHub Pages（推荐：免费、永久、可绑域名）

### B0. 网页版 4 步（不用命令行，推荐）

**第 1 步 · 建仓库**
打开 <https://github.com/new> → Repository name 填 `lp-prototype` → 选 **Public** → 拉到底点 **Create repository**。

**第 2 步 · 上传文件**
新仓库页面点 **uploading an existing file**（或 Add file → Upload files）→ 把 `deploy/` 里的 **7 个文件**全部拖进去：
`index.html`、`rz.html`、`qt.html`、`zq.html`、`README.md`、`.nojekyll`
（`.nojekyll` 是空文件，macOS 下按 `⌘ + ⇧ + .` 显示隐藏文件后才能看到并选中）
→ 点 **Commit changes**。

**第 3 步 · 开启 Pages**
仓库 → **Settings** → 左侧 **Pages** → Source 选 **Deploy from a branch** → Branch 选 `main`、目录选 `/ (root)` → **Save**。

**第 4 步 · 等 1–2 分钟**
刷新 Pages 页面，顶部会出现：

```
https://<你的用户名>.github.io/lp-prototype/
```

这就是可以直接发人的入口页地址。发出去之前自己先用手机打开验一遍。

> 仓库名可以换，地址里的 `/lp-prototype/` 跟着变。用户名是 GitHub 用户名（不是昵称）。

---

### B1. 命令行方式（可选，需要本机已配置 GitHub 凭据）

1. 在 GitHub 新建一个 **Public** 仓库，例如 `lp-prototype`。
2. 把 `deploy/` 里的 4 个文件上传到仓库根目录（网页版「Add file → Upload files」拖进去即可，不用命令行）。

### B2. 开启 Pages

仓库 → **Settings** → 左侧 **Pages** → Source 选 **Deploy from a branch** → Branch 选 `main`、目录选 `/ (root)` → **Save**。

等 1–2 分钟，地址是：

```
https://<你的用户名>.github.io/lp-prototype/
```

### B3. 可选：绑自己的域名

- Pages 设置里填 Custom domain（如 `proto.yourdomain.com`）；
- 在域名 DNS 加一条 CNAME 指向 `<用户名>.github.io`；
- 勾选 Enforce HTTPS。

**判断标准**：微信内打开、且域名已备案 → 不会被提示"非官方网页"；`*.github.io` 在微信内一般可打开，但偶有安全提示，正式对外建议用备案域名。

## C · 腾讯云 CloudBase 静态托管（国内更稳）

1. 登录腾讯云 → **云开发 CloudBase** → 新建环境（按量计费，原型流量几乎为 0）。
2. 左侧 **静态网站托管** → 上传 `deploy/` 里的 4 个文件（保持根目录）。
3. 默认会生成一个 `https://<环境ID>-<随机>.tcloudbaseapp.com` 域名，直接可用。
4. 需要自定义域名时，绑定域名并在腾讯云备案（大陆节点必须备案）。

> 同类可选：阿里云 OSS 静态网站、又拍云、七牛。
> **坑**：OSS / COS 的**默认域名**访问 HTML 可能被强制下载（安全策略）。要直接渲染，需绑定**已备案的自定义域名**并开启静态网站功能。

---

## D · 更省事的托管（可选）

| 平台 | 操作 | 说明 |
|---|---|---|
| **Netlify Drop** | 打开 `app.netlify.com/drop`，把 `deploy` 文件夹拖进去 | 秒出链接；不登录是临时站点，登录后可保留并改域名 |
| **Vercel** | `npx vercel deploy deploy --prod` | 需登录，免费额度足够 |
| **Cloudflare Pages** | 连 Git 仓库或直接上传 | 免费、全球 CDN |

## 部署后自检

打开入口页，逐项确认：

- [ ] 三张卡片都能点开，页面正常渲染（不是白屏、不是下载文件）
- [ ] 手机上打开，机框居中、无横向滚动
- [ ] 点「页面清单」能切到 16 个页面
- [ ] 「看一看」点播放键能进入播放态（当前为占位示意）
- [ ] 地址是 `https://`（微信内要求；http 链接可能被拦截）

## 需要注意

1. **原型是演示数据**：无真实登录、支付、视频、埋点；对外发送时说明这一点，避免被当成线上产品体验。
2. **不要放在需要登录的内网**（如公司 VPN 内网盘），否则外部同事打不开。
3. 三个 HTML 单文件已内联全部图片（合计约 2MB），首次加载稍慢属正常，之后走缓存。
4. 若要长期维护，建议把 `deploy/` 作为仓库根目录，每次更新原型替换对应文件即可，无需改入口页。
